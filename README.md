# Первый ход — шахматный тренажёр для iPhone

Устанавливаемая **веб-версия** шахматного тренажёра «Первый ход» (PWA, не App Store/IPA).

Внутри: **18 дебютов, 61 ветка, 28 уроков и 56 заданий**, тренировки за оба цвета, ручные ходы соперника, подсказки на шахматной доске и встроенный **Stockfish 19 Lite** для ответов вне дебютного репертуара.

## Установка на iPhone

1. Открой адрес этого приложения **в Safari**.
2. Нажми «Поделиться» → «На экран Домой».
3. Оставь включённым «Открыть как веб-приложение» → «Добавить».
4. Открой значок приложения хотя бы один раз с интернетом. После подготовки автономной копии уроки, дебюты и локальный движок доступны без подключения.

Это веб-приложение, не подписанное нативное приложение iOS. App Store, платная подписка или Apple Developer ID не нужны.

## Личные данные и прогресс

- Никакой учётной записи, облачной синхронизации, аналитики или передачи партий на сервер нет.
- Прохождения и собственные PGN-линии сохраняются в локальном хранилище установленного приложения на этом устройстве.
- **Прогресс Mac и iPhone не синхронизируется автоматически.** На Mac: «Мой прогресс → Экспорт JSON». Передай JSON на iPhone через AirDrop или Files и открой «Прогресс → Импорт JSON».
- На iPhone лучше экспортировать резервную копию перед удалением веб-приложения или очисткой его данных. Установленная веб-версия и Safari могут использовать раздельное локальное хранилище.
- Этот адрес общедоступен (публичная статическая веб-страница), но там нет личных партий и статистики пользователей.

## Offline и техническая реализация

Файл index.html содержит весь интерфейс, шахматные правила, учебные программы и JavaScript/WASM Stockfish. Сервисный worker сохраняет файл приложения, иконки и манифест после первоначального запуска по HTTPS, а затем может открывать интерфейс офлайн. Для обновления достаточно открыть ссылку при интернете.

Каталог source/mac содержит основные исходники тренажёра. Каталог source/iphone — iPhone-адаптацию, офлайн-кэш и сборщик. Каталог vendor и файл THIRD_PARTY.md — сведения о компонентах, лицензиях и соответствующий исходный код шахматного движка.

Проверено на мобильных эмуляциях WebKit и Chromium с работающим Stockfish и офлайн-перезагрузкой. Нативное iOS-приложение не создавалось; проверка на физическом устройстве может выявить дополнительные особенности Safari.
